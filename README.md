# C-Neural-Network
A neural network built in C from scratch.

This project consists in **building a neural network in C language**, testing it, and comparing it to other networks. The motivation behind it is the **understanding of how an neural network and everything behind it truly works**, having already experienced the more practical side with the _Blue Aria_ project. The choice of C as a programming language for the project comes from my desire to experiment on a **lower level** than with Python, and because I like it.
