Lecture

  • Début et Fin alimentent la vue Roadmap du Project GitHub. j-p : charge en jours-personnes.
  • Les dépendances sont de type fin-début : une issue ne démarre qu'après la fin de ses bloquantes.
  • Les identifiants sont des repères de ce document. Une bloquante ext: est externe au plan.

Mise en place dans le Project GitHub

  1. Champs Début et Fin (Date), Catégorie et Difficulté (sélection unique) : créés par kickoff.py github.
  2. Ajoutez une vue de type Roadmap. Dans Date fields, choisissez Début et Fin.
  3. Dans View, Group by, choisissez Catégorie. Le regroupement par labels n'existe pas.
  4. Dans Markers, activez les milestones : ils représentent les livraisons.
  5. Les itérations (sprints) se créent dans l'interface du Project.
