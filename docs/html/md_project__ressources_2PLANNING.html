Plan de projet Lia

‍Généré par kickoff.py à partir de plan.json. Pour modifier le plan, éditez plan.json puis relancez la génération. Dates et dépendances issue par issue : `docs/ROADMAP.md`.

Hypothèses

  • Projet personnel, une personne de niveau intermédiaire.
  • Une séance d'environ 1 heure compte pour 1 jour-personne (j-p), les lundis, mardis, mercredis et samedis.
  • Sprints alignés sur les mois civils ; octobre 2026 est fusionné avec novembre, août 2027 s'arrête le samedi 21.
  • La capacité affichée est le nombre de séances disponibles ; la charge planifiée reste sous 80 pour cent, soit au moins 20 pour cent de marge par sprint.
  • Les tâches s'enchaînent dans l'ordre ; la publication de chaque version est placée en fin de sprint et les séances supplémentaires s'ajoutent à la marge.
  • Code en anglais, commentaires en français, compilation en C17 avec gcc.
  • Versions : v1.0 objectif de base (MLP sur MNIST), v1.1 outils d'entraînement, v1.2 performance, v2.0 CNN, v2.1 comparaison finale.
  • Les corrections issues de la relecture du code existant sont traitées hors plan, dans la marge du S1.

Lecture des tableaux : Pers. est la taille du groupe sur la tâche. Diff. : F (facile), M (moyen), D (difficile).

Bonnes pratiques

  • Une branche courte par issue, fusionnée dans main.
  • Messages de commit qui référencent l'issue (closes #12).
  • make test doit passer avant chaque fusion ; à partir de v1.0, la CI le vérifie.
  • Une étiquette git par milestone, avec un journal des changements.
  • Chaque tâche d'étude produit des notes en français dans docs/.
  • Les données (MNIST, Fashion-MNIST, CIFAR-10) ne sont pas versionnées : un script les télécharge.

Points ouverts

  • Numéro du Project GitHub à fournir au lancement (option –project-number) ou à renseigner dans plan.json (project.github_project.number).
  • Choix du framework de tests (issue 1.2).
  • Choix pour M_PI en C17 : constante propre, -D_DEFAULT_SOURCE ou -std=gnu17 (issue 1.1).
  • Environnement Python pour matplotlib (S4) et PyTorch (S10).
