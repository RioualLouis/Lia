Detailed Description

kickoff.py : valider, documenter et synchroniser un plan de projet vers GitHub.

Bibliothèque standard uniquement. Python 3.8 ou plus.
  python kickoff.py validate plan.json
  python kickoff.py docs plan.json --out .
  python kickoff.py github plan.json --dry-run
  python kickoff.py github plan.json
