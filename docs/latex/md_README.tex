\hypertarget{md_README_autotoc_md18}{}\doxysubsubsection{\texorpdfstring{Identified errors}{Identified errors}}\label{md_README_autotoc_md18}

\begin{DoxyItemize}
\item A compiled file is tracked by git that probably shouldn’t be. Compare your {\ttfamily .gitignore} patterns with the name of your executable.
\item {\ttfamily \doxylink{error_8h_source}{error.\+h}} and {\ttfamily error.\+c} disagree on the name of one function. Nothing breaks yet; think about what the linker will say on the first call.
\item In {\ttfamily mat\+\_\+mult}, compare the type of the accumulator with the type of the data it sums.
\item {\ttfamily create\+\_\+random\+\_\+vect} produces integers from 0 to range -\/ 1. Ask yourself what range and sign of values a network’s initial weights should have, and why.
\item {\ttfamily -\/ansi} in the {\ttfamily Makefile} means C89. Fine if intentional, but it forbids some things you may want later (// comments, declarations mixed with code, inline). 
\end{DoxyItemize}
