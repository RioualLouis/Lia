\begin{DoxyItemize}
\item Projet personnel, une personne de niveau intermédiaire.
\item Une séance d\textquotesingle{}environ 1 heure compte pour 1 jour-\/personne (j-\/p), les lundis, mardis, mercredis et samedis.
\item Sprints alignés sur les mois civils ; octobre 2026 est fusionné avec novembre, août 2027 s\textquotesingle{}arrête le samedi 21.
\item La capacité affichée est le nombre de séances disponibles ; la charge planifiée reste sous 80 pour cent, soit au moins 20 pour cent de marge par sprint.
\item Les tâches s\textquotesingle{}enchaînent dans l\textquotesingle{}ordre ; la publication de chaque version est placée en fin de sprint et les séances supplémentaires s\textquotesingle{}ajoutent à la marge.
\item Code en anglais, commentaires en français, compilation en C17 avec gcc.
\item Versions \+: v1.\+0 objectif de base (MLP sur MNIST), v1.\+1 outils d\textquotesingle{}entraînement, v1.\+2 performance, v2.\+0 CNN, v2.\+1 comparaison finale.
\item Les corrections issues de la relecture du code existant sont traitées hors plan, dans la marge du S1.
\end{DoxyItemize}
